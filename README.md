# 고목 GO·MOK

오목판 위에서 치는 고스톱. 7×7 담요에 화투를 한 장씩 내려놓는다. 이어 붙이면 오목, 같은 달이 붙으면 짝(상대 패는 뺏고, 내 패끼리는 잠근다). 판 위 내 패로 족보를 세고 7점부터 고/스톱.

- 바로 하기: https://devlog.moonlang.com/gomok/
- 1분 튜토리얼(훈장님이 한 수씩 안내), 학습 모드(실전 한 판을 두며 매 수 설명·추천 이유·위험 알림·족보 카드 보기·학습 목표, 돈 안 걸림), 컴퓨터와 한 판, 둘이서 한 화면, 온라인 방(링크 공유)
- 표정이 바뀌는 캐릭터 6명, 엎어 쌓은 더미, 부채꼴 상대 손패
- 고스톱 용어 외치기("고도리!" "피박!" "쓰리 고!" 등 32가지 × 두 목소리), 패 내리치는 소리·북·징, 배경 음악, 칸 위치에 따른 좌우 입체음
- 도장·꽃잎·금가루·화면 흔들림 같은 특수효과
- React 18 + htm, 빌드 없음. 설치형 앱(PWA)
